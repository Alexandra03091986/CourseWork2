# 2. "Поиск вакансий"

Этот проект предоставляет возможности получать данные о размещенных на различных сайтах вакансий и позволяет удобно работать с ними: запрос вакансий по ключевому слову, сортировка по зарплате, фильтрация по городу, сохранение в файл, поиск среди сохраненных вакансий.

## Описание

В проекте представлены классы:
- ```Parser```: абстрактный класс, представляющий общую функциональность для запросов с сайтов, размещающих информацию о вакансиях.
  - **Методы**:
  - ```_connecting```: Установка соединения с API
  - ```load_vacancies```: Получение списка вакансий по поисковому запросу
  - 
- ```HeadHunterAPI```: класс предназначен для получения данных с сервера hh.ru.
  - **Методы**:
  - ```_connecting```: Установка соединения с API
  - ```load_vacancies```: Получение списка вакансий по поисковому запросу
  
- ```Vacancy```: класс поддерживает методы сравнения вакансий между собой по зарплате и валидирует данные.
  - **Методы**:
  - Используем ```__slots__``` для экономии памяти
  - ```_validate_salary```: Метод для валидации зарплаты.
  - ```_validate_requirements_and_clean```: Валидация входных данных и очищение требования от HTML
  - ```__eq__```: Проверка на равенство по зарплате
  - ```__lt__```: Проверка: меньше ли зарплата
  - ```__gt__```: Проверка: больше ли зарплата
  - ```__str__```: Строковое представление вакансии
  - ```__repr__```: Красивое представление для вывода списка
  - ```to_dict```: Преобразование вакансии в словарь
  - ```cast_to_object_list```: Простое создание вакансий из данных HeadHunter
  
- ```FileWorker```: абстрактный класс, представляющий общие методы для работы файлами: создание, обновление данных, чтение данных, записанных в файл.
  - **Методы**:
  - ```add_vacancy```: Добавить вакансию в хранилище
  - ```get_vacancies```: Получить вакансии по критериям
  - ```delete_vacancy```: get_all_vacancies

- ```JsonFileWorker```: класс представляет методы для работы файлами формата JSON: создание, обновление данных, чтение данных, записанных в файл.
  - **Методы**:
  - ```_file_exists```: Создать файл если его нет
  - ```_read_file```: Прочитать данные из файла
  - ```_write_file```: Записывает данные в файл
  - ```_is_duplicate```: Проверяет, есть ли уже такая вакансия
  - ```add_vacancy```: Добавить вакансию в JSON-файл (без дубликатов)
  - ```get_vacancies```: Получить вакансии по критериям из JSON-файла
  - ```delete_vacancy```: Удалить вакансию по ID из JSON-файла
  - ```get_all_vacancies```: Получить все вакансии из JSON-файла

Функции:
- ```get_filtered_by_keyword```: фильтрует вакансии по ключевому слову в описании требований.
- ```get_filtered_by_city```: фильтрует вакансии по названию города.
- ```get_sort_vacancies```: сортирует вакансии по зарплате и возвращает топ N вакансий.
- ```print_vacancies```: вывод отформатированной информации о вакансиях.
  
## Использование

1. Запустите скрипт:
   python main.py

2. Следуйте инструкциям на экране:
   - Введите поисковый запрос (например, "Повар").
   - Введите ключевые слова для фильтрации вакансий (например, "Кондитер").
   - Введите город для фильтрации (например, "Москва")
   - Укажите количество вакансий для вывода в топ N.
